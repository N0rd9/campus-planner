# Campus Planner

Campus Planner is a browser-based university dashboard for tracking courses, assignment deadlines, priorities, and estimated GPA. It is built with plain HTML, CSS, and JavaScript so the project is easy to understand, present, and extend.

## Features

- Add and remove semester courses
- Track instructor, credits, and letter grade per course
- Calculate an estimated weighted GPA
- Add assignment deadlines with priority levels
- Mark assignments complete and clear finished work
- Save data in the browser with `localStorage`
- Load demo data for quick testing

## Project Structure

```text
campus-planner/
  index.html
  src/
    app.js
    styles.css
  README.md
```

## How to Run

Open `index.html` in a browser, or run the included local server.

```bash
npm start
```
